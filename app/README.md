# Café StarBuzz — Web (React)

Reescrita em React do protótipo HTML/CSS/JS que está na pasta acima (`../index.html`).

## Rodar
```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # checa tipos e gera dist/
npm run lint
```

Padrão de design e convenções: [DESIGN.md](./DESIGN.md).
